# MP3-Tag-Reader-Editor-C


A C-based MP3 Tag Reader and Editor that allows users to read and edit song information stored in ID3 tags.

## Features

- Read MP3 tag information
- Edit MP3 tag information
- Display song details
- File handling using C
- Command-line based application

## Concepts Used

- C Programming
- File Handling
- Structures
- String Handling
- Command Line Arguments
- Dynamic Memory Allocation
- Functions
